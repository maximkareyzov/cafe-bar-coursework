# Кафе-бар

Курсовой проект: локальное настольное приложение для управления небольшим кафе-баром. Технологии: C#, WPF и .NET 8. План реализации находится в [docs/plan.md](docs/plan.md).

## Состояние проекта

Этап 1: создано главное окно и переключение между разделами. Все разделы пока являются заглушками: база данных, авторизация, заказы, склад и отчёты ещё не реализованы.

## Запуск

Нужны Windows 10/11 x64 и .NET 8 SDK с поддержкой WPF (или Visual Studio 2022 с компонентом «Разработка классических приложений .NET»).

В терминале из корня проекта:

```powershell
dotnet run --project .\CafeBar\CafeBar.csproj
```

В открывшемся окне нажмите на названия разделов слева: заголовок и описание справа изменятся. Для проверки сборки без запуска: `dotnet build .\CafeBar\CafeBar.csproj`.

## Структура

- `CafeBar/MainWindow.xaml` — разметка окна.
- `CafeBar/ViewModels/MainViewModel.cs` — состояние выбранного раздела.
- `CafeBar/Commands/RelayCommand.cs` — команда для кнопок навигации.
- `docs/plan.md` — этапы и вопросы по исходным материалам.
