## Что уточнить до реализации базы

- В ТЗ предусмотрены как локальная SQLite, так и одновременная работа до пяти пользователей по локальной сети. Для многопользовательского режима предусмотрен PostgreSQL; используем ли его в курсовой, нужно согласовать. Размещение SQLite-файла на общей сетевой папке не принимается за проверенное решение для многопользовательской работы.
- В диаграмме `Ingredients.CurrentStock` указан как `varchar`, но в ТЗ остаток — измеряемое количество. Для корректных расчётов потребуется числовой тип; это расхождение нужно согласовать.
- На схеме не видно поля для количества гостей и отдельного поля выхода порции техкарты, хотя оба требования есть в ТЗ. Модель необходимо дополнить при проектировании базы.
- Скидка на конкретный заказ указана в функциональных требованиях, но программа лояльности и дисконтная система исключены из границ проекта. Не добавлять программу лояльности.
